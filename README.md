# 💫 About Me:
My name’s Iago, and I’m a software engineer with 6 years of professional experience building scalable, reliable systems.<br><br>Throughout my career, I’ve worked across multiple languages and paradigms, including Go (Golang), Java, PHP, C++, and C. I have a strong focus on software architecture and Domain-Driven Design (DDD), structuring systems with clear boundaries, clean layers, and long-term maintainability in mind.<br><br>I’ve designed and implemented distributed and event-driven architectures using tools like Kafka and RabbitMQ, and I’m comfortable working in cloud-native environments with Docker and Kubernetes (K8s). I care deeply about performance, scalability, and writing code that not only works — but is structured to evolve.<br><br>My main interests are backend engineering, system design, and building products that generate real impact through clean architecture and solid engineering principles.
